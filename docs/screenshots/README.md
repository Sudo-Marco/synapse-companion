# Screenshots

`floating_pet_offscreen.png` is produced by `tools/capture_floating_pet.py`. It is an offscreen Qt render of the transparent 320×180 floating pet, not a capture of the Windows desktop.

The remaining PNG files are renderer-generated expression captures. They show test states and renderer output; they are not proof of live sensor behavior or an interactive app session. The `ascii/` and `cpu/` subfolders group alternate renderer outputs.
