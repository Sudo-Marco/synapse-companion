# Mockups pixel art: Piu, o canarinho

A arte foi desenhada em pixels inteiros com uma paleta curta; as ampliações usam exclusivamente nearest-neighbor. A sprite sheet tem quadros 32x32 e um sidecar JSON com durações e tags de animação em formato próximo ao Aseprite. Ordem dos quadros: neutro, feliz, cantando, dormindo, assustado, alerta, voo A, voo B e carregando post-it.
